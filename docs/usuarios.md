# Pruebas con usuarios

> **Pendiente (issue #77):** todavía no se ha probado con usuarios. Este documento se llena solo con pruebas reales: personas de verdad, en un teléfono y contra el Firebase real.

## Cómo hacer la prueba

1. Instalar el APK en un teléfono, con las canchas de prueba ya limpias en Firestore.
2. Darle a la persona solo el objetivo, sin explicarle cómo se hace.
3. Pedirle que piense en voz alta. No ayudarle, aunque se trabe: lo que le cuesta es justo lo que hay que anotar.
4. Anotar lo que intentó y lo que falló, tal como pasó.
5. Por cada problema real, abrir un issue y un PR, y anotar aquí el número.

## Objetivos para la persona

1. Crea una cuenta.
2. Busca una cancha de fútbol.
3. Reserva una hora para mañana.
4. Revisa tu reserva y cancélala.
5. Cierra sesión.
